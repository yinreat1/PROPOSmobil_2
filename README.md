# ProPOS Mobil — GitHub + Vercel

Bu klasör yalnızca telefon/PWA yönetim uygulamasıdır. Satış/kasa ekranı içermez.

- Müşteri cari ve borç tahsilatı
- Müşteriye borç para verme
- Ürün arama/düzenleme
- Fiyat/barkod düzenleme
- Stok kontrolü ve stok düzeltme
- Barkod kamera tarama
- Canlı Supabase verisi; mobil tarafta offline satış kuyruğu kullanılmaz

Vercel: Framework Vite, Build `npm run build`, Output `dist`.
Ortam değişkenleri: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`.
